# User guide

For people making and shipping game worlds with piedmont. In the order you will need them:

1. [Running piedmont](running.md): the Docker stack or Kubernetes, and what each service is for.
2. [Creating worlds](worlds.md): find a place, draw it, choose its roads, bake it; what data a bake
   uses, in and outside the United States.
3. [Playing a world](playing.md): game and developer views, the Escape menu, keys and gamepad.
4. [The editor](editor.md): every mode of the world editor: Place, Stage, Assets, Program, Shell,
   Splats and Settings.
5. [Writing a game program](programs.md): the TypeScript game API, winnings and the finish screen.
6. [Generating assets with AI](assets-ai.md): FLUX.2 and TRELLIS.2, self-hosted or hosted.
7. [Driving the editor with an AI agent](mcp.md): the MCP endpoint and its tools.
8. [Deploying to Cloudflare](cloudflare.md): the account, the token, and the Deploy mode.

Operator references for the installs are in [docs/deploy](../deploy/README.md). For working on
piedmont itself, see [DEVELOPING.md](../../DEVELOPING.md).
